# Parent Project Relationship

**Parent repository:** CS-530  
**Child project:** Original Clay Fighter: Papier Parade

This project is a self-contained course deliverable under `projects/original-clay-fighter/`. The parent repository retains shared course resources:

- `.github/skills/` for reusable project skills and workflows.
- Root `README.md` for the CS-530 repository overview.
- `docs/` for course-level planning and research.
- `grok_handoff/` and `grok-handoff-prompts.zip` for the external build-agent handoff package.

Project-specific game source, art sources, runtime assets, tests, build outputs, and evidence should be added beneath this directory. Do not duplicate shared course artifacts unless a project-specific frozen copy is required for reproducibility.
