# Rhinestone Angel G2 — playable character package

**Disposition:** Conditional pass.

The package contains an approved visual bible, editable Blender source, 29 transparent runtime frames, a clip manifest, move and collision definitions, HUD portrait, match renderer wiring, and deterministic special-attack evidence. The guitar-crush finisher is intentionally deferred until the shared finisher system supports multiple targets, camera ownership, skip, and guaranteed return-to-results cleanup.

Remaining release evidence is a real Pygame-ce windowed visual check, controller test, sprite-sheet performance capture, and the shared finisher gate.
