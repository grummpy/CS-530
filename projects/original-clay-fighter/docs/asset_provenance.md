# Asset provenance

Runtime presentation currently uses procedural Pygame rectangles and project-authored YAML data. The handoff supplied 51 synthesized placeholder WAV files and one graybox turnaround image, but neither is present in this repository tree after reconciliation. Blender masters, 1024-square sprite sheets, arena/HUD/button art, and finisher video files were explicitly not delivered. Do not claim those assets exist until their editable source and export provenance are committed.
