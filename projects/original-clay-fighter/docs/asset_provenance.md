# Asset provenance

Runtime presentation uses the approved original stage concept art in `assets/stages/*_concept.png`, created with the built-in image generator on 2026-09-13 and reviewed by the project owner. The accompanying Blender blockouts and the procedural source script are original project work and are retained as editable stage foundations. No real-person imagery, logos, brands, government seals, or supplied Clayageddon character/fatality media were incorporated.

The handoff claimed 51 synthesized placeholder WAV files and one graybox turnaround image, but neither is present in this repository tree after reconciliation. Character sprites, HUD/button art, and finisher video files remain separate production work.
