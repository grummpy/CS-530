# Influence Oracle

Finisher: “Terms Accepted.” Shot 1: a large abstract phone panel frames the rival. Shot 2: generic menu panels compress them into a safe “SKIP” button. Shot 3: Influence Oracle taps it three times, producing soft boing sounds. Shot 4: rival pops back out covered in harmless notification stickers. Reset the scene and return to results.
