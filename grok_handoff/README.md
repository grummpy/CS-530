# Grok Build Handoff: Original Clay Fighter

Use this package as retrieval context for Grok. Start with `MASTER_HANDOFF.md`, then execute prompts in gate order. Each prompt has a bounded objective and defines artifacts Grok must create or update in this repository.

## Package map

| Directory | Purpose |
|---|---|
| `game-engine/` | Pygame-ce engine, combat, input, test, and PyCharm prompts |
| `characters/` | Six independent original-fighter design and asset prompts |
| `sound-effects/` | Audio, VFX, and implementation prompts |
| `additional-art/` | Blender/sprite pipeline, arenas, HUD, and controller overlay prompts |
| `videos/` | Cinematic finisher requirements and shot-by-shot scripts |

The game is original fictional satire. It must not depict or imitate real people, companies, political groups, copyrighted fighters, game assets, logos, voices, quotes, or trade dress. Use theatrical clay, paint, confetti, paper, and harmless prop comedy in place of realistic gore or sexual content.
